## 2026.11.0 (2026-11-03)

First release of the HUBIplan website. It sums up the state after publication as free
software (AGPL); from here on, each release lists its changes in this file.

### New

- Home page built from blocks (welcome, image carousel, events, title holders, results,
  units), news from Instagram and Facebook
- Board, units, event calendar with subscription, titles, honours and statutes
- Chronicle as a timeline with chapters and several images per entry
- Designs from HUBIplan (including custom design packages), preview before publishing
- Fixed texts in German or English

### For operators

- Deployment with a way back, version and rollout log on the server
